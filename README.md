##hamiltonian-graphs-game

O jogo é um quebra-cabeça desenvolvido em Unity baseado no Icosian game. O objetivo é desafiar o jogador a encontrar um caminho Hamiltoniano em diferentes estruturas de grafos.

Um Caminho Hamiltoniano é uma trajetória em um grafo que visita cada vértice exatamente uma vez. No contexto deste jogo:

    Percorrer todos os pontos (nós) do gráfico.

    Não é permitido passar pelo mesmo nó duas vezes.

    O desafio termina quando todos os nós forem visitados (Caminho) e retornae ao ponto inicial

Funcionalidades

    Representação de Grafos: Visualização clara de nós e arestas em um ambiente 2D.

    Interatividade: Clique para traçar o caminho em tempo real.

    Lógica de Validação: Sistema que impede movimentos inválidos e detecta a conclusão do desafio.

Tecnologias Utilizadas

    Engine: Unity
